# 回数台帳（無料版）

回数券・セット契約の「残り回数」を来店ごとに管理する、ブラウザで動くアプリです。

- 契約ごとに回数（サプリなら数量）を登録し、受けた日に選ぶだけで残りが減ります
- 「複数の中から選ぶセット契約」に対応（決まった個数をちょうど選ぶ／上限までの自由選択）
- 体重の記録と推移、来店ペースの分析つき
- **記録はすべてお使いの端末の中だけに保存されます。サーバーへの送信はなく、会員登録も不要です**

## 使い方

1. 下記URLをスマートフォンのブラウザ（Chrome）で開く
2. メニューの「ホーム画面に追加」または「アプリをインストール」を選ぶ
3. ホーム画面のアイコンから起動

初回は「設定 → 記入例を入れる」で動きを確認できます。自分の契約は「残数」タブの「＋ 契約を追加」から登録してください。

## 注意
